在浏览器中开始对局。无需运行本地启动脚本，也无需安装 Node；进入大厅后创建、加入或围观房间。

进入官方服务器

朋友使用自建服务器时，打开朋友提供的完整网址。所有玩家和观众需要连接同一服务端。

局域网房主与本地测试

使用完整 Windows 包并安装 Node.js 18+。如果 Windows 拦截了 启动游戏.cmd，可打开终端进入解压目录，直接运行：

node server.mjs

再访问终端显示的网址；其他设备使用房主的局域网地址。Node 安装包随完整包提供，也可从 Node.js 官网安装。
