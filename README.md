# 潮汐卡牌 · 初版

这是根据 `introduction.md` 做的双人浏览器卡牌游戏。使用原创海洋风格界面与卡面，不依赖外部素材或 npm 包。

对局动画会在攻击时让出手卡突进，受击时短暂震动并浮出伤害数值；卡牌死亡显示退场光效，治疗和睡眠也有对应提示。
胜负判定后会显示结算画面，胜利方有专门的胜利动画。

客户端可以连接当前网页所在的服务端，也可以在大厅选择“自定义公网服务端”并填写服务器网址。双方需要连接同一服务端，再使用房间号创建或加入对局。服务端支持跨域客户端连接和 `/api/health` 健康检查。

## 分发与首次启动

分发 Windows 版本时，把 `启动游戏.cmd`、`server.mjs`、`engine.mjs` 和整个 `public/` 目录放在同一个文件夹，可压缩后发送。玩家解压并双击 `启动游戏.cmd`。启动器会优先使用电脑里已有的 Node.js 18+；如果找不到，会通过 Windows 的 WinGet 安装当前 Node.js LTS，并在安装成功后直接运行游戏。首次安装需要联网，Windows 可能要求确认安装或管理员权限；已有合适 Node 的电脑无需下载。游戏本身不需要 npm 包。

窗口会显示本机网页地址。玩家在浏览器打开后，可选择“自定义公网服务端”，填写同一个联机地址，例如 `https://67.216.204.198:8443`。也可直接在浏览器打开已部署的游戏服务器网页，此时玩家电脑不需要本地环境。

开发和本机测试仍可直接运行 `node server.mjs`。

## 启动

1. 双击 `启动游戏.cmd`，或在此目录运行 `node server.mjs`。脚本会检查并在需要时安装 Node.js 18 或更新版本。
2. 本机打开终端打印的 `http://localhost:端口` 地址。
3. 局域网中另一台设备访问终端打印的 `http://局域网IP:端口` 地址。默认端口是 8080；若被占用，程序会顺延尝试后续端口。若 Windows 防火墙询问，请允许专用网络访问。
4. 一人创建房间，把六位房间码发给另一人；另一人输入房间码加入。

游戏服务端使用 Node.js，界面使用浏览器原生 JavaScript、HTML 和 CSS。无需安装 npm、Python 或游戏引擎。启动器会先找系统里的 Node.js，再尝试当前 Codex 环境附带的 Node；两处都找不到时，会通过 WinGet 安装 Node.js LTS。如果 WinGet 不可用，窗口会给出安装提示。

房间状态只保存在这台电脑的内存中，关闭服务后对局会消失。双方也可以在同一台电脑用两个不同的浏览器或无痕窗口测试。

公网部署步骤见 [部署服务端.md](部署服务端.md)。只有公网 IP 时，HTTPS 步骤见 [HTTPS部署指南.md](HTTPS部署指南.md)。
卡牌规则由服务端的 `engine.mjs` 执行。修改规则后，需更新服务器上的 `engine.mjs` 并重启 Node 服务；界面改动还需同步上传 `public/`。

## 当前规则约定

- 每位玩家从临时牌池随机抽六张。当前牌池是八种已知牌各一张，具体数量等完整卡表到齐后调整 `engine.mjs` 中的 `POOL`；初版没有摸牌。
- 每方四格：靠中央的一排为前排。前排可攻击敌方前、后排；后排只能攻击敌方前排。睡眠中的牌不能行动或被普通攻击、鲨鱼技能选中。
- 睡眠持续到目标持有者下一个回合结束，覆盖一次完整的行动机会。
- 上场、一次性牌与翻车鱼／螃蟹技能不耗行动点；普通攻击、树懒与鲨鱼主动技能耗一点。点数耗尽自动结束回合。
- 企鹅挡伤需要防守方点击“挡伤”或“放行”。企鹅可挡普通攻击、鲨鱼的群攻和追击；海胆反弹在攻击方回合结算，不触发企鹅。
- 海星可以从己方或对方弃牌堆复活非一次性牌，放入己方空格。玩家若回合开始场上无牌，只要手中有海星且双方任一弃牌堆有可复活牌，仍可继续行动。
- 翻车鱼和螃蟹可以用最后 1 点生命发动技能；生命降到 0 时立即进入弃牌堆。
- 一张牌在被海马夺取后进入使用者手牌，重上场时恢复满生命。海星复活的牌也恢复满生命。
- 每名玩家连续两次主动放弃行动点判负。若一方所有非一次性牌离场、且没有可用手牌，则判负。

这些约定会随你后续提供的规则和卡牌说明调整。服务端目前没有账号和持久化存储，适合先做联机测试。
