# Many Fish

双人浏览器卡牌游戏，源自高中时期与同学设计的卡牌玩法。这个 Demo 面向首次公开试玩。

**当前版本：`0.1.0-demo.3` · 许可证：GPL-3.0-only · 发布日期：2026-10-02**

## 开始试玩

### 浏览器试玩（推荐）

直接访问 [官方服务器](https://67.216.204.198:8443/)，或下载 `fish-browser-client.zip`，完整解压后打开 `开始试玩.html`，点击“进入官方服务器”。玩家无需安装 Node，也无需运行启动脚本。官方服务的可用性以本次试玩通知为准。

两位玩家选择同一服务端，一方创建房间，另一方输入六位房间号加入。第三方输入同一房间号并选择“加入观战”，可查看场上牌、战况和手牌数量，不能查看双方手牌或操作对局。

### Windows 本地启动与局域网

1. 从 [Releases](https://github.com/tianrui-huang/fish_card/releases) 下载 `fish-windows-launcher.zip` 并完整解压，不要直接在压缩包内运行。
2. 双击 `启动游戏.cmd`，在浏览器打开启动窗口显示的网址。
3. 两位玩家选择同一服务端，一方创建房间，另一方输入六位房间号加入。

启动脚本会检测 Node.js 18+。缺少环境时先尝试 WinGet，失败后使用 `third_party/nodejs/` 中的 Node.js 24.21.0 x64 离线安装包。安装可能需要管理员确认；失败日志位于 `%TEMP%\tide-card-node-install.log`。

如果 Windows 智能应用控制阻止下载的 `启动游戏.cmd`，公网试玩可改用上面的浏览器入口。本地房主可手动安装包内由 OpenJS Foundation 签名的 Node 安装包，在解压目录打开终端，执行 `node server.mjs`。启动脚本没有受信任的代码签名，当前分发包无法保证被智能应用控制放行。[微软说明](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions)

### 联机方式

| 大厅选项         | 使用方式                                                        |
| ---------------- | --------------------------------------------------------------- |
| 当前页面的服务端 | 两人访问同一个本机、局域网或服务器网址                          |
| 自定义服务端     | 填写完整的 `http://` 或 `https://` 根地址；非默认端口需一并填写 |
| 官方服务器       | 直接选择，无需输入地址；适合受邀玩家公网试玩                    |

局域网：房主启动游戏，把窗口显示的局域网网址发给朋友，双方选择“当前页面的服务端”。Windows 防火墙需要允许 Node 访问专用网络；不同电脑上的 `localhost` 指向各自电脑，不能用它加入朋友的服务端。

直接打开已部署的服务器网页也能试玩，玩家无需安装 Node。官方服务的可用性以本次试玩通知为准。

“返回大厅”提供暂时保留和放弃房间。保留不会暂停游戏，恢复入口仅保存在当前标签页；放弃或胜负结算后返回会关闭房间并释放号码。服务重启会清空所有对局。

玩家和观众可展开“房间聊天”发言；聊天位于操作区下方，不遮挡卡牌和按钮。每条最多300字，每秒最多一条，房间保留最近100条；每个房间最多50位观众。退出观战只移除自己的观战连接。轮到自己行动时会显示提示动画，并更新网页标题。

## 玩法概要

- 两人从同一个42张牌堆各随机抽六张，不放回；开局手牌至少含三张非一次性牌，目前没有后续摸牌。
- 猜拳败者先摆三张，胜者看后摆三张并先行动。每方四格，分前后两排，每排两格。
- 每回合获得一点行动点；上牌和一次性牌免费，普攻与大多数主动技能耗一点，点数耗尽自动换人。主动连续两次弃权判负。
- 最大射程两排：前排可攻击敌方前后排，后排只能攻击敌方前排。非一次性牌普攻均造成一点伤害。
- 生命降到0进入弃牌堆；一方所有牌耗尽判负。场上无牌时，仍有可上场手牌或有效的复活、夺取手段可以继续。

### 特殊情况

- **睡眠**：不能行动，也不能被普攻或鲨鱼技能选中；覆盖目标两次回合，在施加者第二次回合开始时解除。
- **腾空**：立即获得1势能，随后每次自己的回合开始增加1，最多3；睡眠暂停累积。实际受伤后解除腾空并反击，即使致死仍结算；企鹅挡伤则不触发。
- **压制**：清除被压牌的技能状态并禁止操作。攻击该格打到大象，同时被压牌受到来自大象的1伤害；存活的大象由持有者选己方空位返回，无空位死亡。只能由大象的敌方攻击压制格。
- **鲸操控**：持有者、位置、射程与技能规则保留。普攻、袋鼠落击和鲨鱼群攻可选双方其他牌；不能攻击自身，也不能使用免费技能。鲨鱼追击保持所选目标阵营。
- **治疗与复活**：治疗不超过生命上限。翻车鱼、螃蟹可烧掉最后一点生命；同一回合复活不会刷新这张牌的治疗或换取行动点次数。复活和被夺取后重新上场恢复满生命，清空技能状态。

完整技能说明可在游戏内点击卡牌查看。战况记录标明出手玩家、卡牌、普攻／技能、目标及企鹅挡伤情况。


## 开发与发布

运行游戏只需 Node.js 18+，无 npm 运行依赖。JavaScript ES Modules、原生 HTML/CSS；服务端使用 Node HTTP 与 SSE。

```sh
node server.mjs
node --test
```

代码格式使用固定版本 Prettier，开发者首次安装后可执行：

```sh
npm ci
npm run format
npm run format:check
```

修改运行文件后，发布校验会阻止使用旧清单启动。同步更新 `package.json` 和 `public/js/config.mjs` 的版本，格式化后生成清单、测试并打包：

```sh
npm run release:build
npm test
npm run release:check
```

在 PowerShell 中执行 `./scripts/package-release.ps1`，在 `dist/` 下生成客户端、完整服务端和源码分发包。Windows 包含完整源码、测试、构建脚本和 Node 离线安装包；服务端包附带相同版本的源码 ZIP，网页底部提供许可证及源码下载。

文件校验用于识别缺失、改动和版本混用；规则由服务端独立执行。浏览器摘要可以被伪造，无法证明玩家电脑未修改程序，也无法保证恶意局域网房主可信。修改版可以重新生成自己的发布清单并自建服务端；官方对局要求匹配官方发布。

当前没有账号、持久化房间或自动匹配。聊天随房间关闭或服务重启清空。Demo 的规则和联机体验仍会继续调整。
