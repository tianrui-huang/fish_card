# 潮汐卡牌 · 初版

这是根据 `introduction.md` 做的双人浏览器卡牌游戏。使用原创海洋风格界面与卡面，不依赖外部素材或 npm 包。当前包含十一种卡牌，新增袋鼠、大象和鲸；界面会显示睡眠、腾空势能、压制叠牌及鲸的操控提示。

对局动画会在攻击时让出手卡突进，受击时短暂震动并浮出伤害数值；卡牌死亡显示退场光效，治疗和睡眠也有对应提示。
胜负判定后会显示结算画面，胜利方有专门的胜利动画。

战场和战况记录会标明伤害来源：玩家、出手卡牌与位置、普攻或具体技能、受击卡牌和伤害数值。企鹅挡伤前显示待结算攻击，挡伤后标明实际承伤的企鹅及原目标；多只企鹅按位置和剩余生命区分。鲸操控会同时显示操控者，鲨鱼追击、海胆反伤、袋鼠反击和大象压制附加伤害各有标记。

创建房间等待朋友、猜拳及等待对手出拳时，都会显示六张完整手牌。点击卡牌可查看完整技能说明；窄屏下可左右滚动查看。

客户端可以连接当前网页所在的服务端，也可以在大厅选择“自定义公网服务端”并填写服务器网址。双方需要连接同一服务端，再使用房间号创建或加入对局。服务端支持跨域客户端连接和 `/api/health` 健康检查。

## 房间与返回大厅

- 创建或加入后，右上角“返回大厅”提供“暂时保留房间并返回”和“放弃房间并返回”。
- 保留后，大厅的“暂存的房间”可继续原房间，也可放弃；支持暂存多个房间。恢复入口保存在当前浏览器标签页中，刷新仍可继续。保留不会暂停游戏，对手仍可加入或行动。
- 放弃会立即关闭房间并释放房间号；若双方已到齐，另一方获胜并收到结算画面。
- 正常对局结束后，任一方点击结算画面的“返回大厅”，服务端自动删除房间、清除双方凭据并释放房间号；另一方仍可查看结算并返回。
- 同一服务端内尚未关闭的房间号不会重复。已释放的号码可以重新分配，但旧房间的凭据不能访问新房间。

## Windows 启动与分发

直接使用 `fish-windows-launcher.zip`，完整解压后双击 `启动游戏.cmd`。手动打包时，将启动脚本、`server.mjs`、`room-store.mjs`、`engine.mjs`、整个 `public/` 和 `node-v24.21.0-x64.msi` 放在同一个文件夹。游戏不需要 npm 包。

脚本先检查可用的 Node.js 18+，已有环境直接启动。缺失时优先通过 WinGet 安装；WinGet 不可用、连接失败或安装未成功时，自动调用随包提供的 Node.js 24.21.0 x64 安装包，无需下载安装文件。离线安装包适用于64位 Windows；安装时可能出现管理员确认，完成后脚本会重新查找 Node 并启动。安装失败的日志在 `%TEMP%\tide-card-node-install.log`。安装包已核验 OpenJS Foundation 的有效数字签名；大文件保留在工作目录和分发 ZIP 中，不纳入 Git。

在浏览器打开启动窗口显示的 `http://localhost:端口`。联机时选择“自定义公网服务端”，填写 `https://67.216.204.198:8443`，两名玩家使用同一地址和房间号。也可以直接打开服务器上的游戏网页，此时玩家电脑无需运行启动脚本。本机或局域网测试仍可运行 `node server.mjs`；默认从 8080 端口开始，端口被占用时会自动尝试后续端口。

## 服务端维护

Linux 服务端需要 Node.js 18+，文件为 `server.mjs`、`room-store.mjs`、`engine.mjs` 和 `public/`。规则由 `engine.mjs` 结算，房间与凭据由 `room-store.mjs` 管理；修改服务器代码后上传并重启现有的 `card` 服务。界面改动还需同步上传 `public/`。可用 `curl http://127.0.0.1:8080/api/health` 检查服务。房间仅保存在内存中，服务重启会清空对局。

本次伤害来源与企鹅挡伤提示需要更新服务端。现有服务器可使用 `fish-server-update.zip`，将其中的三个 `.mjs` 文件与 `public/` 覆盖到游戏目录，再重启 `card`。具体步骤见 [服务端更新说明.md](服务端更新说明.md)。Linux 服务端不需要 Windows 的 `.msi` 安装包。

当前公网 IP 的 HTTPS、8443 端口和证书续期步骤见 [HTTPS部署指南.md](HTTPS部署指南.md)。

## 当前规则约定

- 双方从同一个42张牌堆各随机抽六张，不放回；剩余30张保留在服务端，目前没有后续摸牌。数量为海星2、海马2、鲨鱼3、袋鼠3、螃蟹4、鲸4、海胆4、大象4、树懒5、企鹅5、翻车鱼6。为保证能按规则摆出三张角色牌，抽到不足三张非一次性牌时重新随机抽取。
- 每方四格：靠中央的一排为前排。前排可攻击敌方前、后排；后排只能攻击敌方前排。睡眠中的牌不能行动或被普通攻击、鲨鱼技能选中。
- 睡眠在施加者第二次回合开始时解除。例如甲施加后，乙的下一回合睡眠，甲再行动，乙又睡眠一回合，到甲再次开始时醒来。睡眠暂停腾空势能累积，保留腾空。
- 袋鼠消耗一点进入腾空，立即获得一点势能；以后每次自己的回合开始再加一点，最多三层。落击消耗一点并解除腾空，按原射程造成 `1+势能` 伤害。实际受伤时解除腾空并以相同数值反击伤害来源，即使本次伤害致死仍反击；企鹅挡下伤害则不触发。
- 大象初始与生命上限均为2，只压制敌方，清除其技能状态并移至其上方；原格位腾空。被压牌不能操作，攻击该格位会打到上方大象，同时被压牌受一点来自大象的伤害并解除压制。存活的大象由持有者选择己方空位免费返回，无空位则死亡。主动解除压制并返回消耗一点，不伤害被压牌。压制中的大象仍计入持有者的在场牌。
- 鲸先选择敌牌，再指定它执行一次耗点行为，整次共耗一点。被操控牌的位置、射程、持有者和技能规则不变；普通攻击或袋鼠落击可指定鲸方的敌牌或己方其他牌。鲨鱼群攻可选双方的一排，排内不攻击鲨鱼自身，击杀后的追击也选同一目标阵营。睡眠和射程限制仍适用；其他技能继续按牌本身的规则执行。免费技能不可使用，影响与反伤的来源仍是被操控牌。操控预览可取消，确认最终行动时才扣点。
- 上场、一次性牌与翻车鱼／螃蟹技能不耗行动点；普通攻击、树懒与鲨鱼主动技能耗一点。点数耗尽自动结束回合。
- 企鹅挡伤需要防守方点击“挡伤”或“放行”。企鹅可挡普通攻击、鲨鱼的群攻和追击；海胆反弹在攻击方回合结算，不触发企鹅。
- 海星可以从己方或对方弃牌堆复活非一次性牌，放入己方空格。玩家若回合开始场上无牌，只要手中有海星且双方任一弃牌堆有可复活牌，仍可继续行动。
- 翻车鱼和螃蟹可以用最后 1 点生命发动技能；生命降到 0 时立即进入弃牌堆。
- 一张牌在被海马夺取后进入使用者手牌，重上场时恢复满生命。海星复活的牌也恢复满生命。
- 每名玩家连续两次主动放弃行动点判负。若一方所有非一次性牌离场、且没有可用手牌，则判负。

这些约定会随你后续提供的规则和卡牌说明调整。服务端目前没有账号和持久化存储，适合先做联机测试。

运行规则测试：`node --test tests/*.test.mjs`。
